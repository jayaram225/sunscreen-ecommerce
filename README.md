# 🛒 Sunscreen E-Commerce Application

## 📌 Project Overview
This is a full-stack e-commerce application built using Spring Boot and JavaScript.

It includes user authentication, product management, cart system, payment integration using Razorpay, and admin controls.

---

## 🚀 Features

### 👤 User Features
- User Registration & Login (JWT Authentication)
- Browse Products
- Add to Cart
- Manage Addresses
- Checkout & Razorpay Payment
- View Orders & Tracking

### 🛠️ Admin Features
- Admin Dashboard
- Manage Products (Add / Update / Delete)
- Manage Orders
- Manage Users

---

## 💳 Payment Integration
- Integrated with Razorpay
- Secure payment verification using backend
- Order creation after successful payment

---

## ⚙️ Tech Stack

### Backend
- Java
- Spring Boot
- Spring Security (JWT)
- MySQL

### Frontend
- HTML
- CSS
- JavaScript

---

## 🔐 Security
- JWT-based authentication
- Environment variables for sensitive data
- No hardcoded secrets
